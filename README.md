## Примеры использования:
1. В пакете *'config'* расположены основные настройки проекта Django.
2. В пакете *'lms'* расположены основные элементы приложения для онлайн-обучения 'lms'.
3. В пакете *'lms'* создан модуль *'urls'* для настройки маршрутизации проекта.
4. В пакете *'lms'* и модуле *'views'* определён вьюсет 'CourseViewSet' для работы с сущностью "Курс".
5. В пакете *'lms'* и модуле *'views'* определены дженерики для работы с сущностью "Урок".
6. В пакете *'lms'* и модуле *'models'* определёны модели данных для Курса и Урока.
7. В пакете *'users'* расположены основные конфигурации приложения пользователя. Сформированы модели, сериализатор, вьюсеты и маршрутизация.
